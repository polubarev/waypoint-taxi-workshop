# Project instructions

Use Context7 MCP for current library, framework, SDK, API, CLI, and cloud documentation. Resolve the library ID before querying one concept at a time. If Context7 is unavailable, record that and consult official documentation.

Use the container engine selected by the participant: Podman and podman-compose by default, or Docker Compose when `TAXI_CONTAINER_ENGINE=docker`. Follow the commands and environment constraints in `docs/development.md`.

Read `.bob/rules/quality.md` and `docs/development.md` before changing the project.
